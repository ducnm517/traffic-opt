# Chaos-aware Traffic Signal Optimization (Work in Progress)

Primary Max-Pressure solver based on : 


`A Max Pressure Algorithm for Traffic Signals Considering Pedestrian Queues` - Liu et al. (2024)

<https://arxiv.org/pdf/2406.19305>

Finite link occupancy based on : 

`Capacity-aware back-pressure traffic signal control` - Gregoire et al. (2014)

<https://arxiv.org/pdf/1309.6484>

# Novel addition
- Time-to-collision
- Post-encroachment time : TTC fails to report danger on near misses, PET is added for accuracy
